# GeneratePressCode - last project by WordPress

## 🧾 Описание проекта

Лендинг для сервиса разработки сайтов, реализованный на **WordPress** с использованием темы **GeneratePress** и блокового редактора **Gutenberg**.

Проект выполнен на основе макета из **Figma**: Gutenberg использовался для построения структуры и секций страницы, а кастомный CSS — для точного воспроизведения дизайна и визуальной части. 

Ссылка на макет:

https://www.figma.com/design/QBr88cyXQua808743NiMZW/CaseRM-Landing-Page--Copy-?node-id=0-1&p=f#frame3 (смотреть третий фрейм)
---

## 📌 О проекте

Это маркетинговый лендинг, представляющий услугу разработки сайтов.
Страница включает:

* hero-секцию с оффером и призывом к действию
* блок «How it works» с описанием процесса
* секцию тарифов с карточками услуг
* адаптивную верстку для десктопа и мобильных устройств

Целью было максимально точно воспроизвести макет из Figma, оставаясь в рамках нативной экосистемы WordPress.

---

## 🛠 Подход к реализации

* структура страниц полностью собрана на **Gutenberg**
* базовые стили обеспечены темой **GeneratePress**
* точная подгонка под макет реализована через **кастомный CSS**
* без использования page-builder’ов и дополнительных плагинов для верстки

---

## 🎯 Результат

Полностью адаптивный лендинг, соответствующий дизайн-макету и демонстрирующий, как можно реализовать кастомный интерфейс в WordPress, используя только нативные инструменты и CSS.
В данном репозитории находится кастомный css код, в случае пересоздания структуры страницы - его можно будет сразу же применить для отображения страницы по макету из Figma.
